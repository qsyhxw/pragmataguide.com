Post-Game / Black Box Mod

Pragmata Black Box Mod Guide

The Black Box Mod is the post-game reward that matters most to ending hunters. It comes from the Architect's vault at the end of the full Unknown Signal route, but simply owning it is not enough. You need to equip it before the final rematch if you want Pragmata's extra ending payoff.

How To Get It What It Does Ending Route

Source

Architect's vault in the Hidden Chamber reward chain.

Combat Value

No stable gameplay benefit documented by current launch-week guides.

Main Use

Triggering the extra ending on the final boss rematch.

// Unlock Path

How To Get The Black Box Mod

The clearest source overlap is that you do not get the Black Box Mod from a single mission. It unlocks only after the full Unknown Signal reward chain is finished and the Architect's vault opens.

The stable requirement set across current coverage is:

  1. Finish the main story once and unlock Unknown Signal.
  2. Reach 100% completion across all five sectors.
  3. Defeat the four enhanced sector bosses.
  4. Clear all 10 Hidden Chamber challenge missions.
  5. Open the Architect's vault and collect the reward set.
Naming note:
Some guides call these Hidden Chamber activities `Secret Missions`, some call them `Sim Pods`, and some call them `Big Cabin challenges`. The stable fact is the count and the completion requirement, not the exact label.

// Reward Set

What Comes Out Of The Architect's Vault

The strongest reward overlap for the final vault is: Lim Cannon, Black Box Mod, and Obsidia outfits for Hugh and Diana.

That split is useful because each reward fills a different role. `Lim Cannon` is the gameplay or build reward, `Obsidia` is the cosmetic reward, and `Black Box Mod` is the narrative-critical reward that matters for ending hunters.

Best simple framing:
If you only care about story payoff, treat Black Box Mod as the one vault item you cannot ignore.

Stable Final Reward Cluster

// Actual Use

What The Black Box Mod Actually Does

Current guide coverage is unusually consistent on one point: Black Box Mod has no combat value. It is not a damage boost, not a survivability perk, and not a general-purpose build piece for ordinary post-game combat.

Instead, its importance is narrative. One guide quotes the in-game description as saying it "may suppress the spread of dead filament in organic life", which is why players immediately connect it to Hugh's condition and the extra ending route.

Do not overread the item:
The item description strongly hints at story meaning, but current public coverage still treats the exact lore implications as interpretation rather than hard-confirmed science text.

// Ending Trigger

How It Connects To The Extra Ending

This is the most important distinction on the whole page: getting the Black Box Mod and using the Black Box Mod are separate steps. The extra ending does not trigger just because the item is sitting in your inventory.

The stable route is:

  1. Collect the mod from the Architect's vault.
  2. Return to the Shelter.
  3. Equip Black Box Mod to Hugh.
  4. Go back to the final rematch in Central Port.
  5. Defeat the enhanced final boss again.
  6. Watch the normal ending sequence continue into the extra post-credits payoff.
Most common mistake:
Players finish Unknown Signal, grab the mod, and assume the ending will change automatically. Current guides agree the equip step is mandatory.

Black Box Mod FAQ

How do you get the Black Box Mod in Pragmata? +

The strongest source overlap says you must finish the full Unknown Signal route: reach 100% completion across all five sectors, defeat the four enhanced sector bosses, clear all 10 Hidden Chamber challenge missions, then collect the Black Box Mod from the Architect's vault.

Does the Black Box Mod have any gameplay effect? +

Current Black Box coverage says it provides no combat benefit. Its importance is narrative: it is the required mod for the extra ending route.

How do you use the Black Box Mod for the extra ending? +

Equip the Black Box Mod to Hugh at the Shelter, then return to the final boss rematch in Central Port and clear that fight again. The extra ending scene only triggers if the mod is equipped before the rematch.

Is the Black Box Mod the only reward from the Architect's vault? +

No. The strongest reward overlap also includes the Lim Cannon weapon and Obsidia outfits for Hugh and Diana, but the Black Box Mod is the reward most directly tied to story completion.
