// Core Rules

How Red Gate Keys Work

They Open Red Zones

Red Gate Keys are the entry item for Red Zones. If you reach a red barrier door without a key, the arena stays closed until you source one from the field or from Cabin's Stamp Club.

They Are Not Region-Locked

A key found in one sector can be spent in another. That is the single most important Red Gate Key rule, because it means your next spend should be based on reward value, not where the key originally came from.

Board Keys Cost Cabin Coins

Stamp Club keys come from bingo-board tiles at the Shelter. If you are short a key, checking the current board is often faster than assuming another field laptop is nearby.

Simple routing rule: if a Red Zone door and a field key are close together, treat that as a convenience loop. If they are far apart, check Stamp Club before over-searching the map.

// Field Pickup Example

Shopping District Key

The clearest early example of Red Gate Key logic is the Shopping District loop. The first Red Zone door appears before the cafe key, which teaches the player that nearby field keys can require a short forward push and immediate backtrack.

// Why This Matters

Keys Feed 100% Cleanup Indirectly

Red Gate Keys are not a normal checklist collectible on their own, but they control access to Red Zones, and Red Zones can award counted items such as Pure Lunum, Mods, and some Storage Expanders.

Best page pairing: use this guide to source keys first, then switch to the Red Zones guide for arena-by-arena reward planning.

// Stamp Club Example

Director Board Reserve Keys

Late in the game, Director board keys act like reserve inventory for the final Red Zone stretch. That is why many complete-route guides treat them as a safety net instead of spending every earlier key the moment it appears.

// Safe Usage

Low-Risk Key Planning

  1. Use nearby field keys first when the return path to the door is short and obvious.
  2. Check Cabin's current Stamp Club board before assuming the map still owes you another field laptop.
  3. Keep at least one late-game key source in mind for the final Central Port double-Red-Zone stretch.
  4. If you are missing counted rewards, audit key sources first, then audit the Red Zones themselves.

// FAQ

Red Gate Keys FAQ

How many Red Gate Keys are documented in Pragmata? +

Current launch-window Red Zone coverage supports 9 documented Red Gate Key sources in total.

Can any Red Gate Key open any Red Zone? +

Yes. Current guides agree that Red Gate Keys are universal and are not tied to specific Red Zone doors.

Are all Red Gate Keys found in the field? +

No. Current key lists split the sources between 4 field pickups and 5 Cabin's Stamp Club board rewards.

Which Stamp Club boards contain Red Gate Keys? +

The documented Red Gate Key boards are Trainee, Associate, Specialist, and Director, with the Director board containing two key rewards.
