Pragmata Ability-Locked Items Guide

This page is a cleanup-first index for the collectibles you cannot fully resolve on first contact. It focuses on the two story-gated route breakers in Pragmata: Lim Eraser for blue Lunafilament, and the late red-filament ability that public guides variously call Cleansing, Cleanse, or Deletion Protocol.

// Blue Barriers

`Lim Eraser` Wave

The early cleanup wave is the cleanest to track. `Lim Eraser` arrives near the end of Mass Production Array and immediately opens a short, well-documented set of return trips in Solar Power Plant and Mass Production Array itself.

// Red Barriers

Late-Game Naming Split

Different sources call the late red-filament tool `Cleansing`, `Cleanse`, or `Deletion Protocol`. The page treats these as one late red-filament unlock when the sources clearly describe the same cleanup function.

// Post-Game

Unknown Signal Safety Net

If you dislike repeated backtracking mid-story, the post-game route remains valid. Current collectible and trophy coverage agrees that collected items carry over and cleanup remains open there.

// Late Cleanup Wave

Documented Red-Filament Returns

The late-game wave is a little messier to name, but the underlying cleanup targets are still cross-checkable. PowerPyx, VGC, GamesRadar+, and GAMES.GG all agree that a second, later filament-clearing ability opens the final sweep of blocked collectibles.

The most stable phrasing is: you get the late red-filament clear after fixing Diana, during the transition into Central Port. Different guides then label the same function as `Cleansing`, `Cleanse`, or `Deletion Protocol`.

Naming note:
Because public naming differs, this page avoids pretending there are three separate systems here. It groups them as one late red-filament unlock and only indexes the item routes that major guides overlap on.

Late Sweep Tip

If you only want one big return pass, this is the unlock to wait for. It resolves the last cross-sector blockages and pairs naturally with Unknown Signal cleanup.

// Best Route

Safest Cleanup Order

  • When `Lim Eraser` unlocks in Mass Production Array, do not just keep moving. Clean Sector 1 immediately, then finish the remaining blue-barrier boxes in Sector 2 while the route is still fresh.
  • Do not over-invest in late red-filament cleanup before you have the actual unlock. Terra Dome and Lunum Mines both have well-documented holdouts that are designed to wait.
  • If you prefer fewer interruptions, save the entire late red-filament sweep for one dedicated pass after fixing Diana or for Unknown Signal cleanup.
  • Prioritize permanent upgrade items first during any return route. In practice that usually means `Storage Expanders`, then `Pure Lunum`, then the remaining Safe Boxes.
  • Use the Tram and your activated Escape Hatches aggressively. Ability-locked cleanup is much easier when you treat return points as route anchors instead of starting every sector from scratch.

// FAQ

Ability-Locked Items FAQ

When do I unlock `Lim Eraser`? +

`Lim Eraser` unlocks automatically near the end of Sector 2, in the Lim Recycling Facility block of Mass Production Array. It is a mandatory story ability used to clear blue Lunafilament barriers.

Why do some guides say `Cleanse`, some say `Cleansing`, and some say `Deletion Protocol`? +

That is a public-guide naming difference, not a reason to assume three separate cleanup tools. Current major guides agree on the late-game function: a red-filament-clearing ability arrives after fixing Diana and opens the last major return routes across earlier sectors.

Can I safely leave these routes for post-game? +

Yes. Current collectible and trophy coverage treats all of these as cleanup-safe. Unknown Signal lets you revisit sectors, and collected items carry over into that cleanup path.

Which return route should I do first? +

The most efficient first return is usually Solar Power Plant after `Lim Eraser`, because it is short, it resolves a `Storage Expander`, and it removes the oldest blocked items from your checklist early.
