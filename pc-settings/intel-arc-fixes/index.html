// First Fix

Start With The Driver

Why 32.0.101.8735 Matters

Intel's official April 21, 2026 driver release notes for 32.0.101.8735 specifically list a Pragmata (DX12) application crash while loading into the game menu as a fixed issue for Intel Arc A-Series, Intel Arc B-Series, and Intel Core Ultra systems with Intel Arc graphics.

What To Do First

If you are below 32.0.101.8735, do not start by endlessly changing in-game graphics options. Update the Intel graphics driver first. For this specific launch issue, the driver is not a generic maybe step. It is the first verified fix.

Shortest version:
Menu crash on Intel Arc: update the graphics driver before changing anything else.

// ReBAR & BIOS

Verify Resizable BAR

Intel's Arc documentation is very clear that Resizable BAR must be enabled for optimal performance. Intel also says Arc can still function without ReBAR, but this is not the configuration you want to troubleshoot performance from if you are trying to get a stable, normal experience.

On Intel's quick-start guide, the required BIOS path is also explicit: disable CSM or Legacy Mode, enable UEFI boot, turn on Above 4G Decoding, and turn on Re-Size BAR Support.

Safe ReBAR Checklist

  • Confirm the system is booting in `UEFI`, not `Legacy` or `CSM` mode.
  • Enable `Above 4G Decoding` in BIOS.
  • Enable `Re-Size BAR Support` or `Smart Access Memory`.
  • Use Intel `Driver & Support Assistant` or Intel Graphics Software to confirm ReBAR is detected.
  • Update motherboard firmware if the ReBAR option is missing or unstable.
Important nuance:
Intel says Arc can still work without ReBAR, but it does not treat that as the optimal target. If you are chasing frame pacing or odd performance swings, check ReBAR before assuming the game itself is the only problem.

// Clean Install

When To Use A Clean Driver Install

Intel's Official Path

Intel's own support article says a clean installation removes old drivers and restores Intel settings to default. If a normal update does not resolve the problem, Intel recommends checking the Execute a clean installation box in the graphics driver installer.

OEM Systems Need Extra Caution

Intel also warns that generic drivers can overwrite OEM-customized drivers. On laptops or prebuilt systems, Intel's own guidance is to check the computer manufacturer first if you suspect platform-specific packaging or stability differences.

Safe Escalation Order

  1. Update to `32.0.101.8735` or newer.
  2. Verify `UEFI`, `Above 4G Decoding`, and `Re-Size BAR Support`.
  3. Retest the game with `RT off` before experimenting with heavier features.
  4. Run Intel's `clean installation` option if the issue remains.
  5. Only after that, move on to a deeper manual clean install path.

// FAQ

Intel Arc Fixes FAQ

What should Intel Arc users do first for Pragmata? +

Install Intel Graphics Driver 32.0.101.8735 or newer first. Intel's official April 21, 2026 release notes specifically list a Pragmata DX12 crash fix for loading into the game menu.

Do I need Resizable BAR for Intel Arc in Pragmata? +

Resizable BAR is required for optimal performance on Intel Arc, though the GPU can still function without it. Intel's own Arc guidance recommends enabling Re-Size BAR or Smart Access Memory, along with Above 4G Decoding and UEFI mode.

What BIOS settings matter for Intel Arc? +

Intel's Arc quick-start guidance says to disable CSM or Legacy Mode, enable UEFI boot, and turn on Above 4G Decoding plus Re-Size BAR Support. Updated motherboard firmware can also matter.

When should I do a clean Intel driver install? +

If a normal driver update does not resolve the issue, Intel recommends using the clean-install checkbox in the graphics driver installer. If that still fails, Intel's support article provides a full manual clean-install path.
