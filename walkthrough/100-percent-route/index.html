// Story Phase

First-Playthrough Route

Play Sector 1 Without Over-Optimizing

Both VGC and GamesRadar treat Solar Power Plant as a sector where some useful items are intentionally unreachable on the first visit. That means the best completionist habit is not to waste time trying to solve every blocked path before the game has given you the tool for it.

Finish Mass Production Array Cleanly

Current guide coverage agrees that Lim Eraser is unlocked toward the end of Mass Production Array. This is the moment where “100% route” starts becoming a real routing problem instead of just “play the story and look around.”

Practical rule: if an early area is blocked by blue crystals, let it go. The first pass is for momentum, not for perfect cleanup.

// Backtrack Window

Post-Lim Eraser Cleanup

Return To Solar First

This is the cleanest early backtrack in current coverage. GamesRadar and VGC both point to Solar Power Plant as the obvious first place to cash in Lim Eraser because its blocked upgrade paths are easy to remember and easy to resolve.

Sweep Mass Production Array While It Is Fresh

Sector 2 itself also benefits from an immediate audit. The area is large, but the game loops you back through relevant spaces late in the level, so this is one of the least painful moments to close blue-crystal gaps.

Do Not Turn It Into A Full-Game Sweep Yet

The point of this cleanup window is to remove the easy early leftovers, not to exhaust every future return case. Terra Dome, Lunum Mines, and late red barriers can still wait.

// Final Sweep

Endgame / Unknown Signal Cleanup

Red Barrier Logic Belongs Late

Current red-barrier guides agree that the second barrier-clearing tool arrives near the end of the fourth level. That is why Terra Dome and Lunum Mines are poor candidates for obsessive first-pass cleanup if you are still seeing red blocks or Dead Filament gates.

Finish The Story Before Starting NG+

VGC's post-game coverage explicitly recommends checking Unknown Signal before New Game Plus. It continues your completed save in the safer cleanup state, which is exactly what a completion route wants.

Use Unknown Signal As The Final Audit Table

Current walkthrough coverage consistently treats Unknown Signal as the best last stop for leftover collectible and completion work. If your file still feels uneven after Central Port, this is the moment to reconcile the missing sectors, the late abilities, and your true-ending prep.

Clean order: finish Central Port, open Unknown Signal, clear any leftover sector work, then move into the Hidden Chamber and the rest of the post-story sequence.

// Route Discipline

Safe Now Vs Safe Later

Safe To Prioritize Now

  • Normal sector flow through Solar and Mass Production Array. Momentum matters more than squeezing every early detour.
  • Solar cleanup after Lim Eraser. This is the highest-confidence early return in the current public guides.
  • Mid-run Shelter checks. Keep REM, upgrade, and reward systems from piling up into one ugly endgame dump.

Safer To Leave For Later

  • Red-barrier leftovers in Terra Dome and beyond. The game simply has not given you the right tool yet.
  • Late cleanup in maze-like sectors. Central Port and Unknown Signal are better checkpoints for a calmer audit.
  • NG+ decisions. Handle Unknown Signal and your 100% file first, then decide if you want another run.

// FAQ

100% Route FAQ

What is the best 100% route in Pragmata? +

The strongest current route is to play the first two sectors normally, use Lim Eraser for the first deliberate cleanup pass, continue through the later sectors without forcing every red gate, then finish the file in Unknown Signal before moving on to New Game Plus.

When should I backtrack in Pragmata? +

The first important backtrack point is right after unlocking Lim Eraser in Mass Production Array. Late red-barrier cleanup is safer after the red-clearing story ability is unlocked near the end of the fourth level.

Should I do Unknown Signal before New Game Plus? +

Yes. Current post-game guides recommend checking Unknown Signal first because it continues your completed save in the best state for leftover completion work.

Can I still get 100% if I miss early collectibles? +

Current walkthrough coverage treats early missed collectibles as recoverable through late abilities and post-story revisit windows, which is why this route favors clean timing over panic-clearing every room on the first pass.
